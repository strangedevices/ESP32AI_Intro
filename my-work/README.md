# my-work

Your own projects go here, one folder per stage, for example `my-work/02-harness`.

The idea of the workshop is that you build each stage yourself with Claude Code first, and
only reach for `Reference Implementations/` if you are stuck or short of time.

How to start a stage:
1. Open a terminal in the top folder of the repo and run `claude`.
2. Paste the starter prompt for the stage from `starter-prompts/`, or better, write your
   own prompt describing what you want. The stage's README in `stages/` says what "done"
   looks like.
3. Let Claude Code build, flash and test. Read what it changes. Push back when it is wrong.

Things that keep it smooth:
- Projects must sit exactly two folders below the top of the repo (like
  `my-work/02-harness`) so they can find the shared `secrets.h` in the top folder.
- Your work here is yours. Commit it to your own fork if you want to keep it.
