# Starter prompts

Prompts to paste into Claude Code (run `claude` in the top folder of the repo) to build a
stage yourself in `my-work/`. They describe what to build, not how. Change them, shorten
them, or write your own: seeing how the result changes with the prompt is the point.

They are different from `fallback-prompts/`, which get the finished reference
implementations running when you are stuck.

| Stage | Prompt |
|---|---|
| 02 | `02-wifi-and-ui.md` |
| 03 | `03-voice-recorder.md` |

Stages 00 and 01 have no starter prompt: you flash what is provided, then change it.
